Question 01 1 Point

What is the primary function of the Input Layer in an artificial neural network?

Explanation: Input nodes do not carry weights or perform activations; their sole task is translating external data into standard numeric arrays (tensors).
Question 02 1 Point

Why is Data Normalization (e.g. scaling input values between $0.0$ and $1.0$) essential before model training?

Explanation: Scaling ensures all features contribute proportionally during gradient descent updates, preventing huge numbers from destabilizing optimization.
Question 03 1 Point

How do Hidden Layers extract patterns from raw data?

Explanation: Deep networks build abstractions layer-by-layer, starting from basic pixel edges and progressing to complex features like snout shapes or dog eyes.
Question 04 1 Point

What happens if a neural network does NOT use any Activation Functions?

Explanation: Stacking linear combinations without non-linear activation functions simplifies to a single linear equation ($W_{\text{combined}} X + b$), destroying deep learning capabilities.
Question 05 1 Point

Which activation function acts like a threshold switch, outputting $0$ for negative values and preserving positive values as $f(z) = \max(0, z)$?

Explanation: ReLU is widely used because it is computationally efficient and helps prevent vanishing gradients for positive signals.
